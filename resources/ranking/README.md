# 排行角色插图

九款透明 PNG，专用于排行榜右上角；插件卡片继续使用根目录的 `logo.png`。

- `yachiyo-wave/peace/heart/hug/pout/laugh.png`：六款 Q 版，分别为挥手、比 V、比心、抱小兽、鼓腮和大笑。
- `yachiyo-normal-smile/wave/hug.png`：三款正常比例半身图，分别为指脸颊笑、招手欢迎和开心抱小兽。

这些是以《超时空辉夜姬！》月见八千代为灵感、通过内置 imagegen 绘制的非官方同人素材，无文字或水印。眼角采用较柔和的弧线。全尺寸原图为 1254×1254，安装素材经等比缩小为 576×576 RGBA，保留透明度，在 288×288 槽位内显示。

每次排行随机选择，进程内避免连续同款；不可读素材会被跳过。仅余一款可用时允许复用，全部不可用时仍显示排行正文。打包检查要求九张 PNG 完整包含。
