# 本轮 review 修复

印象刷新以调度时取得的完整批次作为证据，并在摘要成功后提交该批次进度。`impression.interval` 同时决定触发条件和批次大小，提示词不再单独截断为 20 条。失败或证据被撤销时不前移进度；手动刷新也使用相同批次规则。模型会收到整批流水，修改间隔前应考虑上下文长度和费用。

群排行入口先确认存在群身份，再选择 Bot 运行空间。私聊命令与排行工具明确提示在群聊使用，不尝试解析群数据库，也不吞掉身份校验异常。

三维流水撤销使用关系值域（亲近度 ±100），旧标量流水沿用原配置范围。预览与事务写入调用同一个边界选择函数，避免预览批准了实际无法写入的数值。

独立修复版本通过 317 项离线测试、Black 和项目规范检查；包含真实调用提取后的命令/工具方法、完整印象批次和新旧流水边界回归。该版本不依赖后续分级评估模块。

后台执行时重新读取有效流水并核对固定批次 ID；调度后的撤销会使本次刷新取消，不发出无法提交的摘要调用。提交时仍复查，覆盖模型调用期间的撤销。
