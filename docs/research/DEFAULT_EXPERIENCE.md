# 默认体验审阅：更快初识，控制重复增长

审阅基准：main `dc22bf9032ce5d7c4a33506074e9e6501a5b4778`，运行版本0.2.6。此前用于对照的 `0d40b13af6acc1c2ec1d2ef7d6c9b553c65134bb` 与该基准仅有README和研究文档差异，生产代码相同。交付前已同步main `1b73adbf46d2982c90a69ed89cf7ec7922830a2b`（0.3.0）；该更新以文档、元数据和格式整理为主。本次候选版本0.3.1，不修改schema。

## 采用的调整

- 默认词典的F分界从10/25/40/70改成1/5/40/70：更早显示眼熟、相识，后期保持原节奏。F/A/T实际增量、上限与存量均不重算；亲近与信任不随初识称谓加速。
- 整句问候覆盖早上好、午安、晚上好等常见说法，忽略末尾常见语气词与边缘装饰。只做整句匹配，问候后接实质内容仍进入评估。白天/夜间一视同仁，不把说错时段当作欺骗或恶意。
- 新安装默认开启亲近度衰减，初始半衰期30天、巩固上限120天。只影响A，F/T不随沉默变化；临时覆盖和事务仍沿用现有逻辑。它是面向长期群聊的产品默认，不是心理学定律或已验证的普遍最优值。
- 明确旧配置与真实行为的区别；详细设置不再提供当前文字排行用不到的图片字体/分列。近期事件最多10条、恢复抑制系数至少1，与实际使用范围一致。

## 对照方法与结果

`python scripts/review_default_experience.py --output <新的空目录>` 使用固定时钟、合成身份、真实FavorService/AssessmentService/SQLite。问候Provider故意始终返回friendly、confidence=0.99；这不是对任何真实模型的准确率测量。结果中的源码摘要用于区分工作树与基准提交。回归旧过滤器时，在基准检出中运行同一脚本；公开摘要分别保留前后源码身份。运行目录中的临时数据库不提交。

800次增长事件按普通问答/友好互动、每天2/10次对照。只有词典分界不同，逐次实际分值完全一致；称谓反馈提早，不增加持久化更新。摘要见 [离线结果](DEFAULT_EXPERIENCE_RESULTS.json)。

这里“眼熟/相识”指F分档，最终复合称谓还由A/T决定。每天10次友好互动会触及每日F上限，不能用次数×0.3代替真实轨迹。1/5与2/8候选均保留在报告中；选择较快候选是产品取舍，不声称人类盲评胜出。

42次问候尝试的间隔为0、30、121、242、363、484秒：旧版“早上好/晚安喵/晚安啦”各进入5次评估并累计F+1.5/A+2.2/T0；本次均为零调用、零增量。原本就过滤的纯“早安/晚安/晚安加标点表情”保持零增量。较长睡前请求仍可评估；不能声称所有低信息改写和语义重复都已解决。

衰减用初始A=5/20/60/−20、F=40、T=−20，比较0/1/7/30/60/180天读取。A=20且未巩固时，旧10天半衰期在第30天为2.5；30天候选为10；关闭时保持20。F/T均不变，查询不新增流水、不改存储原值。正向互动的巩固、旧档位托底和临时暂停沿用既有实现；此处不能推断真人感受。

## 兼容、失败与回滚

已有`decay.enabled=false`、10/60天或其他显式参数继续生效。配置缺少某字段才采用新默认；要维持完全不衰减，应显式关闭。历史记录自身的半衰期不批量重置，首次启用时可能按既有时间锚产生有效A变化。读取不物理改分，后续正式写入仍会结算衰减。升级前备份由维护者安排，本次不操作生产库。

词典版本升为2；无需数据迁移。回滚代码恢复旧称谓；回滚默认值需恢复原配置，不能假称已结算的衰减会自动恢复。任何需恢复的存量状态应使用既有备份/审计工具。

自动评估、注入、诊断仍保持关闭，不自动选择/升级模型。小模型误判容忍通过本地过滤、受限映射、冷却/限幅和弃权实现；没有将confidence当校准概率，也没有新增模型调用或关系维度。

## 尚未解决

- 较长重复请求、反讽与实际改正识别仍依赖有限语境。普通批评不应因内容负面而扣T；本次未改事件协议或默认负向权重。
- 当前默认仍没有经过验证的正向Trust修复路径；管理员调整、A衰减和A恢复抑制均不算Trust修复。
- 诊断分段上限可能提前淘汰记录；印象汇总的额外并发/模型选择及普通运行日志内容仍需独立整理。没有为了默认设置审阅重构这些路径。
- 页面运行并发显示、成员分页/折叠和三维流水展示由独立面板改动处理。
- 真实弱模型误判率、真人偏好、长期群聊改善、真实Token成本与浏览器视觉均未验收。
