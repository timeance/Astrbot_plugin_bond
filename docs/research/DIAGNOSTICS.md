# 0.5.1 分级诊断

诊断仍默认关闭，启用后的详细程度默认「评估记录」。旧配置只开启总开关而缺失 detail_level 时，AstrBot 按 schema 补全为 assessment；直接装配时也使用 assessment。已保存的 raw、evaluation、full 选择保留。等级依次为：

1. 评估记录：原有状态、关系变化、耗时和用量。
2. 原文+评估：本次相关消息、可信引用及可取得的 Bot 回复。
3. 评估上下文：评估调用前实际冻结的输入、初评/复核输出。
4. 完整上下文：再添加 Bond 请求钩子所观察到的人格提示、历史消息、关系注入、可序列化工具定义和结果。后续插件或 Provider 变换不在承诺范围内，也不记录模型隐藏思考。

所有内容仅本地保存，不增加模型调用。内容按消息 trace 关联；原文证据的正式关系流水仍独立保留。诊断清除只作用于当前 Bot 和关系空间的诊断副本，清除前的在途采集也不能重新落盘；之后新消息照常记录。降低档位不自动抹除先前保存的内容。历史记录不能补出当时未采集的原文。

容量默认 100 MB（十进制），可设置 1–10000 MB，全 Bot/空间共用；页面显示实际落盘大小，队列另计。7天是最大保留窗口，容量轮转可能提前删除。启动及运行期间定期清理过期文件，包括关闭采集时；插件未运行时无法执行清理。

只选择请求内容字段，不导出 Provider 对象、配置或认证头。结构化敏感字段过滤，JSON 字符串中常见凭据字段和明显密钥模式替换；不保存媒体文件、base64或带签名地址。文本仍可能含个人信息，不能承诺匿名或完整自动脱敏。内容和队列有界，截断有标识。异常数值、未知对象及深度超限用 null 替代并计入预算；有效快照再次检查内容不变，避免导出把自身写出的截断记录误判为损坏。历史文件不自动重写；导出复检拒绝仍含上述未脱敏字段的行，并计入损坏行缺口。诊断故障不阻断回复。

以下保留旧版本设计和历史测试结果；与上文冲突的旧限制仅描述历史版本。

# 可选关系诊断记录

日期2026-11-02；依赖关系词典PR #20，基准6caafd8f800dd9ce5a20b85decb732343fba07d6。版本0.2.5，schema仍为15。研究只使用合成事件和预置Provider，不连接真实服务。

## 0.3.4 留存修正

原实现每次 flush 新建文件，合成600次单条 flush 会先触及512个文件上限，即使离20MiB很远也开始淘汰。现同一次加载、同一 Bot/空间、同一 UTC 日向最新片段追加，单片段仍最多256KiB；保持起始mtime，避免追加延长保留期或倒置片段顺序。旧文件和行schema可继续读取。7天按片段起始时间清理，因此同日较晚记录可能提前不足一天过期；容量和文件数仍可能使窗口更短。

导出上限由4096提高至32768行，仍显示截断和历史缺口未知。每消息只做有界字段整理及入队；磁盘线程每批扫描/排序至多512个片段，不查询关系库或模型。新默认与观察记录见 [RECOMMENDED_DEFAULTS](RECOMMENDED_DEFAULTS.md)。以下原0.2.5验证数字为历史快照。

## 决策与复杂度

采用一个默认false开关 diagnostics.enabled、一个插件级记录器及现有TaskRegistry。记录器不查询关系库、不反向影响评分，不建立事件总线、群友图、第四维或另一套审计真相。FavorService仍是关系唯一写入口，诊断只是事务完成后的旁路观察；重复/冷却时记录实际零增量。管理员编辑、重置和临时关系记录操作类别，后几类不补查完整前后状态。按群撤销可以记录来源；全局撤销没有可靠来源群时只计缺口，不用全局数据库键关联成员。重置保留请求的真实来源群。诊断准备或发送异常被隔离，不能让成功提交变成失败返回。

词典独立以常数次分档查表。诊断按字段白名单收集现有结果，不进行语义推断，不调用模型、不采集新上下文。旧标量设置、自动衰减及恢复备份不逐次生成完整诊断变化记录；该导出不是正式流水替代品。模式/配置/人格切换不自动生成可关联的人格历史。

## 数据合同

每行仅含版本、加载会话代号、Bot/模式/群/成员代号、时间、事件类别和有限结构字段：已发生的F/A/T前后值与增量、维度档位、词条键、政策版本、词典版本、规则配置摘要、状态、失败类别、Provider档位、Token和耗时。confidence仅是未经校准的模型建议。

不接受聊天/引用正文、昵称、模型原始输出、自由文本错误、Provider地址、管理员备注或密钥。普通接口不展示诊断。导出按Bot和per_group/global选择；全局空间的群/成员代号也按来源群隔离。每次加载随机HMAC密钥，不持久化；同一事件的调用/评估/变化可在同次加载同分区内关联，重载及跨群不关联。时间与轨迹仍有间接识别风险，称为脱敏而非匿名。

文件名使用私有Bot/模式摘要以定位旧记录；管理员导出不含该摘要。配置摘要只覆盖关系规则、限幅、经济/衰减及初始化参数，不包含Provider、提示词或人格配置；不能靠它完整重建真实语义评估。

关闭时正常消息路径不创建目录、随机标识或后台任务；管理员明确导出/清除历史例外。旧关系流水原有正文存储不受此开关影响。

## 资源与失败

同步emit只校验、复制小字段并入队；单writer通过线程执行磁盘IO。队列256行，单行2KB，单文件256KB，最多512文件、128个Bot/模式计数组合；整个诊断目录总上限20MB。超过队列/命名空间上限丢弃，超过容量/文件数轮转最旧文件，状态显示缺口。

写入和导出时清理7天以前文件；无活动时不启动定时删除。容量、文件数及导出32768行上限都可能使可用窗口短于7天，不能把上限当完整保留保证。计数仅当前加载有效，历史缺口明确未知。仅支持一个插件实例独占诊断根目录；遇到外来文件或链接拒绝写入/删除并记失败。

清除在同一锁内排除旧队列和进行中的批次；清除后新事件可继续记录。写线程取消时先等待实际IO结束再释放锁，避免旧批次回填；极慢磁盘可能延长卸载等待，不是主回复同步IO。清除失败通过API返回失败，不显示已清除。清除/导出从不操作正式SQLite库。

## 复现与回滚

在offline环境运行，输出目录必须新建且为空：

~~~text
python -m pytest tests/ -q
python -m black --required-version 26.5.1 --check .
node --test tests/dashboard.test.cjs
python scripts/check_project.py
python scripts/replay_diagnostics.py --output <新目录>
python scripts/summarize_diagnostics.py <管理员导出.json> --output <本地摘要.json>
~~~

真实框架隔离环境：

~~~text
python scripts/smoke_astrbot.py --session-dir <新目录> --runtime-dir <新目录>/runtime
python scripts/smoke_message_metadata.py --session-dir <另一新目录>
python scripts/smoke_diagnostics.py --runtime-dir <第三个新目录>
~~~

提交后执行python scripts/build_package.py --output <归档.zip>，该命令从HEAD构建。远端CI须对应最终PR提交；本地检查不替代远端结果。提交仅含合成指标，不包含实际诊断导出或数据库。

回滚可先关闭diagnostics.enabled并重载，必要时恢复0.2.4代码与配置；schema没有变化，正式关系无需迁移或重算。关闭后可先导出/清除旧诊断，再回滚。仅该独立记录目录受容量清理影响。

真实QQ、真实Provider、真人盲评、Angel Heart同装及浏览器流程保持未验收。后续先按GOLDEN_SET.md获得许可与独立双标注，再评价词典贴切性及语义误更新；本轮不把诊断日志当金标准。


JSON 工具内容按结构识别敏感字段，数字、布尔、null、对象和数组同样脱敏，转义的字段名也会识别。解析限制为32768字符、8层和4096节点；不完整或超过限制的JSON整段省略。容器和列表元素均计入内容预算，避免嵌套空容器拖慢请求；这些省略不影响正常回复。
