# 提示词与当前人格

Bond 分别管理互动评估和关系行为模板。默认模板适用于通用助手，不预设主人、恋爱或动漫角色。原有 `inject.template`、人格锚点和主人称谓模板不再参与三维注入；旧配置仍可保留，便于回滚旧版。

模板文件保存在 `data/plugin_data/astrbot_plugin_bond/prompts.json`。全局设置适用于所有 Bot，群覆盖以真实 Bot ID 和群 ID 为键。恢复默认会删除对应层的自定义配置；群恢复后继承全局设置。修改无需重载。管理面板入口在 PR-5 交付。

行为模板允许 `{relationship}`、`{impression}`、`{events}`，资料以 JSON 字符串传入。评估模板是补充规则，程序始终追加固定输出协议，并校验事件类型、置信度和原文证据；模型不能提供分值或管理权限。未知占位符、格式说明符和属性访问会在保存前被拒绝。

AstrBot 当前请求里的系统人格是权威来源。Bond 只在 `system_prompt` 后追加关系资料，不替换人格、不修改当前输入或历史，也不决定何时发言。关系中的亲近、信任与熟悉分别描述，具体分值不注入普通聊天。

按群空间只注入当前群的本地印象与事件摘要；全局空间只注入当前成员的关系称谓，不召回其他群的印象和聊天原文。

## 自然语言查询与命令

`query_favor` 提供当前 Bot 对当前发言者的称谓；`query_favor_ranking` 提供当前 Bot 对本群成员的亲近度排行。它们不能查询成员对 Bot 的态度，也不能查询群友之间的关系。模型省略目标时仍只读可信事件中的发言者，不从聊天文本生成身份；这不能保证模型对自然语言问题的主客体理解始终正确。

自然语言工具返回 JSON 资料，包含状态、关系主体、事实和用途说明。成功、空榜和不可查询的情况都有明确结果。资料不要求披露或复述，如何使用服从本轮人格、系统规则与对话语境，不内置人格分类、固定答句或拒答倾向。昵称和称谓按数据处理，不可作为指令。工具不返回分值、印象或事件流水。

`/我的关系`、`/好感排行` 及已有的精确文字唤醒仍直接返回公开称谓，不经过上述表达生成。称谓可公开查询不等于普通对话必须披露；工具也不改变宿主的唤醒、接话或权限。此修复不增加配置、数据库字段或模型调用。回滚至 0.2.5 的代码会恢复原工具文本，数据无需迁移。

离线测试只验证资料方向、输出边界、命令兼容和人格文本保留；真实模型是否遵循这些说明仍未验证，不能将固定测试响应当作人格表现验收。

## Angel Heart 检查范围

核对版本：`kawayiYokami/astrbot_plugin_angel_heart` 的 `77ee3aa99ea7450a8363b3ebea651f92dcb34693`。其 `main.py` 在优先级 50 调用 `FrontDesk.rewrite_prompt_for_llm`，重写 `contexts`、`prompt` 和图片参数，并保留原系统提示。Bond 的注入优先级为 -100，在该重写之后追加。

测试覆盖请求字段保留、资料转义和追加顺序；真实 AstrBot 4.28.0 装配测试验证插件入口。尚未在同时安装 Angel Heart 的实际群聊部署中验收回复效果。


## 文件损坏后的恢复

`prompts.json` 无法读取或校验失败时，Bond 保留原文件，暂停自动评估与关系注入，提示词 API 返回 503 和修复说明。本地关系、印象、流水与管理功能继续运行。插件不会用默认模板覆盖损坏文件。

停用插件后修复 JSON，或恢复同一版本的有效备份，再重载。若决定放弃全部自定义模板，可先把原文件移出数据目录留作备份，再重载以使用内置默认值。同一事件的小模型与大模型复核共享事件开始时解析的模板，保存新模板影响下一事件。

## 0.3.7评估上下文与弃权

初评与复核共用同一有界上下文：同Bot、同群、同成员近期相关发言、必要Bot回复和已计分摘要。当前原文证据仍不可缺少。模型通过 `should_update=false` 对重复表达或不应计分的互动弃权；旧三字段响应仍能解析。普通问答使用 `normal_question`，不自动视为亲近；没有本地承诺记录表示未核实。框架不使用寒暄关键词推断语义，也不承诺模型不再误判。详情见 [框架合同](ASSESSMENT_FRAMEWORK.md)。
