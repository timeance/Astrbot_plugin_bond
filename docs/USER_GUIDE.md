# Bond 用户指南

## 安装后设置

使用 AstrBot `>=4.28` 和 OneBot `aiocqhttp`。通过插件管理从仓库安装，或将源码解压到 `data/plugins/astrbot_plugin_bond/`，目录名保持全小写。手动安装时保留根目录 `logo.png`。已做装配验证的框架版本与实际验证范围见 [验收记录](ACCEPTANCE.md)。

重载后打开 Bond 管理页面，连接 OneBot，点击“刷新 Bot 列表”，选择账号和数据空间。Bot 身份来自平台连接或可信消息事件，一个适配器可以连接多个账号。仅填写适配器配置而尚未连接或收到事件时，列表可能为空；此时仍可配置模型与基础开关。私聊可以帮助登记账号，关系功能用于群聊。

| 想要的效果 | 设置方法 |
| --- | --- |
| 互动后自动变化 | 手动选择日常评估模型，再开启自动评估。日常模型须明确选择。 |
| 自动积累或扣减信任 | 选择分级复核并配置复核模型。信任事件须满足证据与两次判断条件。 |
| 回复参考关系 | “详细设置 → 个性化功能”中的“在回复中体现关系”新安装默认开启，已有明确关闭的选择保留。也可参考手动设定的关系。 |
| 使用动态称谓 | 同一区域开启“动态称谓”。默认关闭，模型留空时跟随复核模型，两者均未配置时使用固定称谓。 |
| 限定群聊 | 设置 `group_whitelist`，留空适用于所有群。范围外保留历史资料供管理员管理。 |
| 排除其他机器人 | 在基础设置填写需要忽略的 Bot 账号。 |

新安装默认使用 Galgame，眼熟模式默认开启，自动评估与诊断默认关闭。自动评估在后台处理，失败时正常聊天继续。关系参考由当前人格组织表达，关系高低只提供相处资料。

Bond 页面保存基础或详细设置后需重载插件，已开始任务使用原配置完成。AstrBot 原插件配置编辑同一份配置，宿主保存时自动重载。在两处切换编辑时先刷新表单。Bond 页面会拒绝过期版本的保存，提示刷新后重试。提示词单独保存，成功后立即生效。

## 群聊查询与命令

以下命令用于已启用 Bond 且在适用范围内的群。公开查询返回当前 Bot 对成员的关系资料。

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/我的关系` | 所有群成员 | 查看 Bot 对发言者的关系称谓。 |
| `/我的印象` | 所有群成员，需开启 | 返回关系称谓，或结合当前人格生成一句话印象。 |
| `/好感排行` | 按配置 | 查看本群前 10 名，按亲近度排序，显示昵称、头像与关系称谓。 |

### 我的印象

在“详细设置 → 查询与排行”选择“我的印象”的输出方式，默认关闭。“输出关系称谓”直接读取称谓，“大模型总结”使用当前会话聊天模型和人格，结合称谓、标签与已有印象生成一句话。超时、异常或无有效回复时回退称谓，查询本身保持成员状态与印象存储。

“你对我有什么印象”“你觉得我怎么样”等自然语言问法由聊天模型调用 `query_my_impression`，需要宿主正常接话并支持工具调用。需要确定入口时使用斜杠命令。该工具只查询发问者本人。全局空间只使用共享关系称谓，本群输出的印象资料按群范围读取。

### 排行权限与图片

“查询与排行”可选择所有人或仅主人。仅主人模式按 Bond 的主人 QQ 名单与可信发言者账号匹配，名单为空时无人可查。斜杠命令、文字唤醒与模型工具使用同一权限。已发送的榜单可以被群内成员看到和转发。

默认图片排行使用内置中文字体和九款八千代角色插图，榜内最多 10 人，查询者高亮。昵称缺失时显示“未命名成员”。图片失败时使用现有回退方式，也可关闭图片使用文字。自然语言查询由当前人格组织表达。群聊查询展示关系称谓，数值和私有证据在认证管理面板查看。

### 管理员快捷命令

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/好感设置 <QQ号> <数值>` | 宿主管理员 | 设置当前空间的亲近度，支持一位小数与负值。 |
| `/好感重置 [QQ号]` | 宿主管理员 | 重置指定成员；按群空间下不带参数可清空本群关系数据。 |
| `/关系设置 <QQ号> [类型]` | 宿主管理员 | 设置关系标签，省略类型时清除。 |
| `/印象设置 <QQ号> [标签1,标签2]` | 宿主管理员 | 设置最多 3 个标签，每个最多 6 个字符，逗号分隔；省略标签时清除。 |
| `/印象刷新 <QQ号>` | 宿主管理员 | 根据最近未汇总的有效评估记录刷新印象。 |

## 三维关系与变化

| 维度 | 数值范围 | 表示的状态 |
| --- | --- | --- |
| F 熟悉度 | `0..100` | 陌生、眼熟、相识、熟悉、熟络。 |
| A 亲近度 | `-100..100` | 疏远、疏淡、平和、亲近、亲密。 |
| T 信任度 | `-100..100` | 戒备、谨慎、保留、放心、信赖。 |

三维分别计算。初始均为 0 时显示“陌生”，随着互动可逐渐出现“眼熟之人”“浅交之人”“寻常相识”等表达；相处也可能同时亲近和戒备。固定词典有 76 词，三维各五档形成 125 格主状态，并保留 20 处局部展示细分。范围与含义见 [关系词典](RELATION_LEXICON.md)。

普通有内容问答可以增加 F。亲近取决于合格互动，信任取决于有记录的可靠行为及证据核验。持续尊重边界满足 14 天内 3 条独立证据时，基础奖励 +1 T，Galgame 为 +2 T，每 5 天最多一次。感谢、示好、承诺和道歉本身的 T 为 0。管理员可查看证据与撤销流水。

Galgame 将正向请求与正向每日额度乘 2，基础模式按基础规则计算。两种模式共用衰减设置。默认保温期 5 天，F/A/T 默认半衰期为 30/30/60 天，基线为 10/0/20；资格、额度、托底和精度的完整规则见 [评估框架](ASSESSMENT_FRAMEWORK.md)。在对应维度分区修改后保存并重载，“恢复此区默认设置”会先填入表单，检查后再保存。

动态称谓在实际互动时观察到任一维度跨过 5 分边界后，按默认 12 小时间隔尝试刷新。观察包含自然衰减带来的跨界。每个 Bot 每 UTC 日最多 30 次生成或校验调用，一次刷新最多 3 轮，通过即止。可延长间隔或降低每日上限，0 表示暂停。查询和排行复用有效缓存。关闭动态称谓保留缓存，重新开启可复用有效缓存；需要更新时继续使用固定称谓，等下次跨桶再尝试。完整模型与缓存规则见 [评估框架](ASSESSMENT_FRAMEWORK.md#关系称谓)。

## 印象与标签

印象刷新间隔 `impression.interval` 默认为 8，累计单位是上次成功汇总后未撤销、未汇总的有效自动评估流水，包含因每日额度等限制留下的零变化评估流水。管理员手动调整按资料管理流程处理。一次自动评估实际更新关系后，累计达到间隔才尝试后台汇总。

按群模式各群分别积累，全局模式同一 Bot 同一成员跨群积累。模型不可用或生成失败时保留原内容和待汇总记录。默认一句话模式同时更新印象与最多 3 个标签，分点模式 `impression.points_mode` 更新要点并保留标签。临时关系期间暂停自动更新。

## 使用管理面板

面板跟随 AstrBot 当前浅色或深色主题，右上角按钮可以临时切换本次主题。每次打开重新跟随宿主。写操作由宿主认证保护。

| 入口 | 操作 |
| --- | --- |
| 当前总览 | 按群、QQ 号筛选，查看三维、称谓与标签。尚无关系变化的成员默认折叠，可展开或搜索。 |
| 显示印象 | 在总览切换为印象视图，保留状态与标签，已有印象最多显示两行。切回“显示数值”恢复三维列。 |
| 成员详情 | 查看最近互动、完整印象、近期评审；刷新昵称、正式调整三维或编辑印象。 |
| 变动流水 | 按群、QQ、维度或自动评估来源筛选，查看原因和证据，预览并撤销整个事件。群聊活跃记录支持查看组内成员并逐人撤销。 |
| 提示词 | 编辑行为与评估模板，支持全局、Bot 与群级覆盖、草稿预览和恢复默认。 |
| 评估 | 查看初评、复核、上下文、窗口与额度，区分保存值和当前运行值。 |
| 详细设置 | 按基础、个性化、各维变化、印象、查询与诊断分区编辑。 |
| 备份与恢复 | 在顶部展开，对选定 Bot 当前空间在线备份，或按备份文件名确认恢复。 |

### 今日概览与状态

今日概览中的初评、复核次数按所选 Bot 跨群与数据空间合计，UTC 换日，失败也计入。变动人数按配置时区与当前空间统计，三维任一实际改分或撤销均计入，同一成员只算一次。临时覆盖和自然衰减按各自状态展示。筛选、搜索与翻页保持概览统计范围，点击刷新重新读取。

状态中的彩色 F、A、T 表示正在衰减的维度，三轴均在衰减时只显示“衰减中”。负 T 向基线恢复仍显示 T 衰减中。临时关系生效时优先显示“临时关系”。“最近互动”取三个维度最近的真实维护时间。

### 临时关系体验

成员详情的调整方式可切为“临时调整”，设置 1 分钟至 30 天的三维覆盖。期间公开称谓、排行和回复参考使用临时值，详情保留正式值与到期时间。自动评估、自动印象更新和正式衰减暂停，覆盖前已发出的任务按原有有效性校验处理。

到期或点击“立即结束临时关系”后恢复正式值，再继续衰减与评估。期间消息跳过补评。覆盖持久保存，重启后继续生效。结束后可以调整正式分数、撤销分数流水或重置，印象与标签仍可手动编辑。

### 昵称与群资料

“全部群”显示 QQ 昵称，指定群显示群名片，缺少群名片时回退昵称。旧记录缺少可靠昵称时显示“昵称未知”。刷新昵称需要对应 Bot 在线，同一成员至少间隔 30 秒，失败保留原资料。

全局空间的“全部群”可查看和调整正式关系，群资料与事件操作仍需选择具体群。多 Bot 使用不同 AstrBot 配置时，每份配置都需启用 Bond，并允许目标群。热更新后详情参数无效时，先重载插件并刷新页面，必要时重启 AstrBot。

## 数据空间与维护

| 空间 | 归属与用途 |
| --- | --- |
| `per_group`，默认 | 按 Bot、群与成员分别记录。 |
| `global` | 同一 Bot 跨群共用成员关系，本群排行仍只包含本群已观察成员。 |

切换空间只切换数据路由。每个 Bot 独立使用 `data/plugin_data/astrbot_plugin_bond/bots/{bot_id}/group.db` 和 `global.db`。全局空间的临时关系同样跨群共用，按群空间只作用于选定群。Bot 专属空间选择优先于 `default_scope_mode`。

升级前成组备份代码、宿主配置和整个插件数据目录。0.6.0 的一次性信任配置升级说明继续适用，已完成后保留后续设置。0.7.0 兼容旧称谓开关与已知旧默认值，见 [升级说明](MAINTENANCE_UPGRADE.md)。

提示词保存在独立 `prompts.json`，群级覆盖按可信 Bot ID 与群 ID 保存。文件损坏时保留原文件并暂停评估和注入，本地查询与管理继续可用。修复后重载，模板协议与占位符见 [提示词说明](PROMPTS.md)。LivingMemory 集成的取舍见 [接口调查](LIVINGMEMORY.md)。

## 数据与模型调用

| 功能 | 发往何处及内容 |
| --- | --- |
| 自动评估 | 所选评估 Provider，包含消息与允许的同 Bot、同群、同成员上下文及必要 Bot 回复。 |
| 印象刷新 | 所选印象模型，包含允许汇总的有限流水。 |
| 动态称谓 | 指定称谓模型，留空跟随复核模型，包含完整有效人格、当前三维事实和允许参考的本群印象。全局空间省略聚合印象。 |
| “我的印象”总结 | 当前会话聊天模型，包含当前人格、关系称谓、标签与已有印象。 |
| 图片排行 | 固定 QQ 头像服务，仅榜内至多 10 名成员账号，用于获取头像。头像短时缓存于内存，失败使用占位，图片在本机生成。 |
| 关系诊断 | 本机保留与导出，按所选档位记录。 |

诊断默认关闭，启用后的默认档位为 `assessment`。`raw` 增加消息与回复，`evaluation` 增加评估内容，`full` 增加主请求内容，已有明确选择保留。成员与事件使用临时代号，已知凭据模式会脱敏，详细档位仍可能包含私人对话，分享前逐项检查。

默认保留约 7 天，全部 Bot 与空间合计默认最多 100MB，可配置 1–10000MB。当前空间可查看、导出或清除，关闭后仍可管理旧记录。清除后在途任务按批次隔离，详细规则见 [诊断说明](research/DIAGNOSTICS.md)。提交 Issue、PR 和截图时使用合成资料，真实聊天、账号、数据库与密钥保存在自己的环境。

## 进一步核对

自动评估依赖当前 Bot 的可信指向、原文证据与模型语义判断。归属冲突、无法复核、额度不足或失败时本次跳过评分。主人标记按可信账号匹配，仅供当前人格表达使用。唤醒和接话由 AstrBot 或对应插件控制。

管理接口见 [管理功能](PR5_MANAGEMENT.md)，被动熟悉度见 [眼熟模式](PASSIVE_FAMILIARITY.md)，离线及真实框架的验证范围见 [验收记录](ACCEPTANCE.md)。行为对照材料见 [行为验收](P0_BEHAVIOR_EVALUATION.md)，建模与原始 References 入口见 [评估框架](ASSESSMENT_FRAMEWORK.md#references--参考资料)。
